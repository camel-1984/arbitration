# Сколько стоит машина банкрота

Когда человек банкротится, его машину продают с торгов. Стартовую цену ставит арбитражный управляющий, обычно так: открывает Авито, смотрит похожие объявления, ставит примерно столько же. Потом машина без осмотра, с залогом и неизвестным пробегом три месяца не продаётся, цена падает по графику, и все грустят.

Этот проект пытается грустить меньше: модель смотрит, за сколько похожие машины реально ушли на завершённых торгах, и показывает диапазон, за который, вероятно, уйдёт эта. Стартовую цену по-прежнему выбирает управляющий, но уже с ориентиром.

> 25% похожих машин продаются дешевле 610 тыс. руб., 50% дешевле 700 тыс., 75% дешевле 790 тыс.

Решение остаётся за управляющим. Модель не видела машину вживую и не знает, что в багажнике.

## Что внутри

- **Данные:** около 15 тыс. проданных легковых лотов с площадки ЦДТ (torgi.cdtrf.ru) с 2024 года. Персональные данные маскируются при парсинге.
- **Признаки:** марка, модель, год, мощность, объём двигателя и флаги состояния (не на ходу, после ДТП, залог, арест, нет документов, машина неизвестно где), достаются регулярками из текста лота.
- **Задача:** квантильная регрессия P25/P50/P75 на логарифме цены продажи, функция потерь pinball loss.
- **Метрики:** MdAPE по медиане, покрытие коридора P25-P75.
- **Модели:** медиана похожих лотов → линейная регрессия → CatBoost. Победитель определяется на валидации по времени, а не заранее.

Подробности в [docs/design.md](docs/design.md).

## Статус

Данные собраны, признаки достаются, модели ещё нет. Цифры появятся здесь, когда бейзлайн перестанет быть планом.

## Запуск

```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m src.collect.cdtrf --since 2024-01-01
.venv/bin/python -m src.parse.cdtrf
.venv/bin/python -m src.dataset.build
```

Сбор идёт вежливо, порциями примерно по часу. Сайту плохо не делаем.

## Структура

```
src/collect   скачивание карточек лотов
src/parse     HTML → data/interim
src/features  извлечение признаков из текста
src/dataset   interim → data/processed
src/labels    эталонная разметка и проверка регулярок
src/eda       помощники для ноутбуков
docs          дизайн-документ и правила разметки
web           интерфейс для управляющего
```
