# Сколько стоит машина банкрота

Когда человек банкротится, его машину продают с торгов. Стартовую цену ставит арбитражный управляющий, обычно так: открывает Авито, смотрит похожие объявления, ставит примерно столько же. Потом машина без осмотра, с залогом и неизвестным пробегом три месяца не продаётся, цена падает по графику, и все грустят.

Этот проект пытается грустить меньше. По завершённым торгам он отвечает на три вопроса:

1. Сколько обычно ставят другие управляющие на такую машину.
2. Как часто похожие лоты продаются сразу, на первых торгах, при той или иной начальной цене.
3. За сколько машина, вероятно, уйдёт: «25% похожих машин продаются дешевле 610 тыс. руб., 50% дешевле 700 тыс., 75% дешевле 790 тыс.»

Решение остаётся за управляющим. Модель не видела машину вживую и не знает, что в багажнике.

## Что внутри

- **Данные:** 17,7 тыс. проданных легковых лотов и 26,7 тыс. первых торгов (проданных и нет) с площадки ЦДТ (torgi.cdtrf.ru) с 2023 года. Персональные данные маскируются при парсинге.
- **Признаки:** марка, модель, год, мощность, объём двигателя и флаги состояния (не на ходу, после ДТП, залог, арест, нет документов, машина неизвестно где), достаются регулярками из текста лота.
- **Модели:** цена продажи и типичная начальная цена - квантильная регрессия P25/P50/P75 (ансамбль линейной регрессии и CatBoost), продажа на первых торгах - классификация (логистическая регрессия и CatBoost, вероятность монотонно падает с ростом цены).
- **Валидация:** по времени, кварталы 2025 года; 2026 год отложен для финальной проверки.

Подробности в [docs/design.md](docs/design.md).

## Статус

Финальная проверка на лотах 2026 года, которые не использовались при выборе моделей: цена продажи - типичная ошибка 26,7% (с начальной ценой управляющего 21,1%) против 34% у медианы похожих лотов; типичная начальная цена - 24,0%; продажа на первых торгах - вероятности откалиброваны (средняя ошибка 0,9 п.п.), AUC 0,77. Это на уровне кросс-валидации на 2025 годе. Модели обучены на всех данных и лежат в `models/`. Дальше - пилот с практикующим управляющим.

**Как поставить и пользоваться (Windows):** [docs/pilot_guide.md](docs/pilot_guide.md).

## Запуск для разработки

```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt
PYTHONPATH=. .venv/bin/python -m uvicorn src.api.app:app --port 8001
```

Сбор и подготовка данных:

```bash
.venv/bin/python -m src.collect.cdtrf --since 2023-01-01
.venv/bin/python -m src.parse.cdtrf
.venv/bin/python -m src.dataset.build
```

Сбор идёт вежливо, порциями примерно по часу. Сайту плохо не делаем.

## Структура

```
src/collect   скачивание карточек лотов
src/parse     HTML → data/interim
src/features  извлечение признаков из текста
src/dataset   interim → data/processed
src/labels    эталонная разметка и проверка регулярок
src/eda       помощники для ноутбуков
src/models    модели и валидация по времени
src/api       сервер для сайта (FastAPI)
journal       журнал экспериментов
docs          дизайн-документ, правила разметки, API, гайд для управляющего
web           интерфейс для управляющего
```

Учебный проект курса ML, ИТМО.
