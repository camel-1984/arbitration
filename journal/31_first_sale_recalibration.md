# 31_first_sale_recalibration

## Question / hypothesis

Уменьшит ли перекалибровка по последним кварталам (сдвиг свободного члена или Platt) отставание модели 3 от падающего тренда?

## Motivation

- **Sourcing strategy:** my-pick
- **Source(s):** B19; доля продаж сразу упала с 36% до 14% за три года.
- **Why this matters:** цифра «продаётся сразу в X%» должна оставаться честной при сдвиге рынка.

## Method

- **Files touched:** `misc/scratch_2026-10-16/exp31.py`.
- **Change versus baseline (or previous experiment):** для фолда Q модель учится на train до (начало Q − 3 или 6 мес.), прогнозирует последние 3 или 6 мес. train (их исход известен до начала Q), по ним подбирается сдвиг логита или Platt (наклон и сдвиг); потом модель на всём train, прогноз Q с поправкой.
- **Cross-validation:** честный CV из 26, кэш фолдов `m3.py`.
- **Out of scope for this experiment:** перекалибровка по сегментам.

## Risks / things that could invalidate the result

- Последние месяцы train - тот же отрезок, что тренд по месяцам уже видит: поправка может быть около нуля.

## Status

- **State:** done
- **Approved by user on:** 2026-10-17 («максимально улучшай третью, пока не упрётся»)
- **Headline result:** текущая модель log loss 0.3603 / ECE 0.014; сдвиг логита по последним 3 мес. 0.3723 / 0.021, Platt 3 мес. 0.3722 / 0.020, по 6 мес. 0.3751-0.3760 / 0.028-0.031. Подобранный сдвиг по фолдам меняет знак (от −0.23 до +0.50).
- **Implication for next iteration:** не принимается: сдвиг между кварталами меняет знак, то есть это колебания доли продаж от квартала к кварталу, а не устойчивое отставание; поправка по последним месяцам переносит их в следующий квартал и только добавляет ошибку. Долгий тренд уже держит кусочно-линейный сплайн месяца в логистической.
