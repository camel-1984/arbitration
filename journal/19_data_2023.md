# 19_data_2023

## Question / hypothesis

Улучшатся ли модели, если добавить в обучение проданные лоты, опубликованные в 2023 году?

## Motivation

- **Sourcing strategy:** my-pick
- **Source(s):** кривая обучения (раздел 2.3, разбор после 02): MdAPE на 2025Q4 снижалась с 30.4% до 27.5% при росте train с 2 до 8 тыс. лотов и не вышла на плато; в дизайне 2.2 оговорено, что 2023 год добавляется, если данных не хватает.
- **Why this matters:** последний крупный рычаг для модели без стартовой цены, который не требует новой информации о машине.

## Method

- **Files touched:** сбор `--since 2023-01-01` (4840 новых карточек, 0 ошибок, всего 19 845), перепарсинг с исправленной маскировкой VIN и квартир; `src/dataset/build.py` (`SINCE`) - только если вариант выиграет.
- **Change versus baseline (or previous experiment):** парное сравнение на одном перепарсинге: `SINCE` = 2024-01-01 и 2023-01-01; фолды CV не меняются (кварталы 2025), 2023 год только расширяет обучение. Каталог всех статусов для связки этапов начинается с 2022 года.
- **Cross-validation:** честный CV из 04; бейзлайн, ансамбль без старта и со стартом.
- **Out of scope for this experiment:** 2022 год.

## Risks / things that could invalidate the result

- Дрейф цен 2023 года (после скачка 2022): признак месяца учитывает только линейный тренд.
- Для лотов начала 2023 года цепочка первых торгов может начинаться до 2022 года и не найтись (тогда правило 0.9).

## Status

- **State:** done
- **Approved by user on:** 2026-10-16 (общее разрешение работать над улучшением модели)
- **Headline result:** 2023 год даёт 4446 лотов (train фолда 5318 → 9764). Ансамбль: без старта 27.3% → 28.4%, промах > 50% 27.0% → 30.0%, pinball 0.176 → 0.180; со стартом 21.9% → 23.3%, pinball 0.143 → 0.146; бейзлайн 38.3% → 36.0%. По моделям: CatBoost 29.2% → 28.0%, линейная 27.9% → 31.8%; линейная с кусочно-линейным трендом по месяцам на 2023+ - 28.1%, но на 2024+ такой тренд хуже (29.9%). Гибрид (линейная на 2024+, CatBoost на 2023+): без старта 26.9% / pinball 0.174, со стартом 22.5% / 0.143.
- **Implication for next iteration:** не принимается: выигрыш не больше 0.4 п.п. и только у модели без старта, ценой двух окон обучения. Линейный тренд по месяцам не описывает рынок 2023-2025 (излом цен), а линейная модель - главная часть ансамбля. 2023 год собран и лежит в данных; к нему стоит вернуться, если тренд будет моделироваться иначе (например, индекс цен по кварталам из CatBoost).
