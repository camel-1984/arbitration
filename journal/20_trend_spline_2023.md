# 20_trend_spline_2023

## Question / hypothesis

Станут ли данные 2023 года полезны, если в линейной модели заменить прямую линию тренда по месяцам на кусочно-линейный тренд с изломом и линейным продолжением?

## Motivation

- **Sourcing strategy:** my-pick
- **Source(s):** 19: с 2023 годом CatBoost улучшается (29.2% → 28.0%), а линейная ломается (27.9% → 31.8%) из-за прямого тренда; сплайн с постоянным продолжением на 2023+ давал 28.1%, но терял свежий тренд.
- **Why this matters:** +4.4 тыс. лотов в обучении без новой информации о машинах.

## Method

- **Files touched:** `src/models/linear.py` (`months` через SplineTransformer: degree 1, `TREND_KNOTS` = 3 узла по диапазону train, extrapolation linear), `src/dataset/build.py` (`SINCE` = 2023-01-01), `src/models/ensemble.py` (`WIDTH_K` пересчитан последовательной схемой 12).
- **Change versus baseline (or previous experiment):** перебор узлов 3 / 4 / 6 на 2023+ и 2024+ для линейной модели, затем ансамбль на 2023+ в обоих режимах.
- **Cross-validation:** честный CV из 04, фолды - кварталы 2025.
- **Out of scope for this experiment:** —

## Risks / things that could invalidate the result

- Узлы ставятся равномерно по диапазону месяцев train фолда, то есть положение излома зависит от фолда; выбор 3 узлов сделан на тех же фолдах.
- Линейное продолжение последнего отрезка на тесте 2026 может переоценить тренд, если рынок развернётся.
