# 14_start_ratio

## Question / hypothesis

Улучшится ли модель со стартовой ценой, если дать ей отношение стартовой цены к рыночной оценке модели без старта через сплайн?

## Motivation

- **Sourcing strategy:** my-pick
- **Source(s):** 08: зависимость цены продажи от старта с переломом (при старте ниже рынка лот уходит по старту на первых торгах, при старте выше рынка цена тянется к рынку); линейная часть ансамбля видела `log_first_price` только линейно.
- **Why this matters:** перелом объясняет двугорбое распределение на лотах, проданных на первых торгах.

## Method

- **Files touched:** `src/models/ensemble.py` (`add_start_ratio`), `src/models/linear.py` (сплайн по `start_ratio` в режиме со стартом), `src/models/catboost_model.py` (`start_ratio` в признаках со стартом).
- **Change versus baseline (or previous experiment):** `start_ratio` = log(first_price) - P50 линейной модели без старта. На train - прогноз вне фолда (5 фолдов KFold внутри train, seed 0), на валидации - модель на всём train. Линейная: сплайн 6 узлов, 3 степень; CatBoost: числовой признак.
- **Cross-validation:** честный CV из 04, данные 11 + связка 08, коридор из 12.
- **Out of scope for this experiment:** модель без старта не меняется.

## Risks / things that could invalidate the result

- Стекинг: рыночная оценка на train вне фолда, на валидации - на всём train; небольшое различие качества оценок между train и валидацией.
- Коэффициент ширины коридора подбирался до изменения, покрытие 54.7% - нужен пересчёт k.
