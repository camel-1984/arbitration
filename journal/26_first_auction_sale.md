# 26_first_auction_sale

## Question / hypothesis

Насколько хорошо по машине и начальной цене предсказывается, продастся ли лот на первых торгах, и откалиброваны ли эти вероятности (модель 3, design doc 2.1)?

## Motivation

- **Sourcing strategy:** user (B10, основной вектор работ 2026-10-17)
- **Source(s):** для управляющего лучший исход - продажа на первых торгах; в 21 классификатор «продан на аукционе» по проданным лотам дал AUC 0.75, то есть сигнал есть.
- **Why this matters:** шкала «цена → шанс продажи сразу» - главный блок ответа в новом интерфейсе.

## Method

- **Files touched:** `src/collect/cdtrf.py` (`--ids`, `--cards-dir`), `src/dataset/stages.py` (`first_auctions`), `src/dataset/first_auction.py`, модуль `src/models/first_sale.py` (написан до результата, повторяет схему скрипта; принимается или переписывается по итогам), сбор карточек первых торгов в `data/raw/cdtrf/cards_first/` (21 853 карточки, около 5 ч), scratch-скрипт `misc/scratch_2026-10-16/exp26.py`; модуль в `src/models/` - после результата.
- **Change versus baseline (or previous experiment):**
  - Объект: первые торги машины по каталогу всех статусов (только «Легковой транспорт», аукцион с ценой больше 0, без более ранних торгов той же машины у того же должника за 18 месяцев: то же название, VIN или марка+модель), опубликованные с 2023 года, с известным исходом. Отменённые и незавершённые исключаются.
  - Таргет: статус «Подписан договор» (продан на первых торгах, в том числе единственному участнику). Доля в 2023-2025: 36% → 23% → 14% по годам.
  - Признаки: те же, что в задаче 1, из текста карточки самих первых торгов (что было известно в момент публикации), плюс log начальной цены и её отношение к P50 модели 1 без старта (OOF внутри train, как `start_ratio`).
  - Модели: логистическая регрессия на признаках линейной модели, CatBoost-классификатор с монотонным убыванием по отношению цены к рынку, среднее вероятностей.
  - Бейзлайны: доля продаж сразу за последние 4 квартала train; логистическая регрессия только на отношении цены к рынку и месяце.
  - Метрики: log loss, Brier score, AUC, кривая калибровки по децилям прогноза.
- **Cross-validation:** фолды - кварталы 2025 года по дате публикации первых торгов; в train только первые торги, завершённые до начала квартала; модель 1 для отношения обучается только на лотах, проданных до начала квартала.
- **Out of scope for this experiment:** повторные торги (другая ситуация: лот уже отвергнут); сценарий публичного предложения - это задача 1.

## Risks / things that could invalidate the result

- Сильный тренд: доля продаж сразу упала с 36% до 14% за три года. Калибровка на прошлых кварталах может отставать.
- Шум разметки: торги срываются и по процедурным причинам.
- Причинности нет: дешевле ставят и на машины похуже, модель описывает похожие лоты, а не эффект снижения цены.
- При подготовке данных была выведена доля продаж сразу в 2026 году (12.7%): для решений не используется, финальный тест не тронут.

## Status

- **State:** done
- **Approved by user on:** 2026-10-17 (основной вектор работ, «погнали, делай»)
- **Headline result:** 26 746 первых торгов 2023-2025 (19 119 до 2026 после фильтров train/valid), продано сразу 23% (2025: 14%). Среднее по 4 фолдам 2025: ансамбль (логистическая + CatBoost с монотонностью) log loss 0.360, Brier 0.109, AUC 0.763, средний прогноз 14.0% при факте 14.4%; бейзлайны - доля за 12 мес. 0.424 / 0.127 (прогноз 19.4%: отстаёт от тренда), отношение цены к рынку + тренд 0.367 / 0.110 / AUC 0.761; логистическая на всех признаках 0.374 / AUC 0.741, CatBoost 0.369 / AUC 0.765, но средний прогноз 16.7% (по фолдам 13-24% при факте 11-17%). Калибровка ансамбля по децилям: от 2.6% / 3.8% до 46.3% / 41.7%, ECE 0.014. Факт по отношению старта к рынку: ниже рынка на 33% и больше - продано сразу 48%, на уровне рынка 21-30%, выше на 80% и больше - 4.5%. Средний прогноз при старте × 0.7 / 1.0 / 1.3 от фактического: 0.22 / 0.13 / 0.09 (2025Q1).
- **Implication for next iteration:** принято как первая версия модели 3 (`src/models/first_sale.py`). Почти весь сигнал - отношение цены к рынку и тренд: простой бейзлайн почти равен ансамблю по AUC. CatBoost плохо держит тренд (средний прогноз прыгает по фолдам) - это B16; отношение к типичной цене - B17.
