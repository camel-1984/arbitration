# 13_optional_start

## Question / hypothesis

Работает ли одна модель, обученная со стартовой ценой, где у половины обучающих лотов цена стёрта, так же хорошо, как две отдельные модели (со стартом и без)?

## Motivation

- **Sourcing strategy:** user
- **Source(s):** вопрос пользователя 2026-10-16: одна модель, а управляющий может указать стартовую цену, а может не указать.
- **Why this matters:** одна модель проще в поддержке и переобучении; если она не хуже в обоих режимах, вторая модель не нужна.

## Method

- **Files touched:** только scratch-скрипт; код моделей меняется, только если вариант выиграет.
- **Change versus baseline (or previous experiment):** в train каждого фолда у случайных 50% лотов (фиксированный seed) `first_price` заменяется пропуском. Линейная модель получает индикатор пропуска (SimpleImputer с add_indicator), CatBoost обрабатывает пропуск сам. Дублирование строк (каждый лот со стартом и без) не используется: в CatBoost копия лота видела бы таргет оригинала через ordered target statistics. Валидация в двух режимах: со стартом и со стёртым стартом. Сравнение с двумя отдельными моделями 08 (P50, промах > 50%, pinball до калибровки ширины, покрытие после калибровки с k из 12).
- **Cross-validation:** честный CV из 04, данные 11 с полной связкой 08.
- **Out of scope for this experiment:** другие доли маскирования.

## Risks / things that could invalidate the result

- В линейной модели индикатор сдвигает только общий уровень, веса остальных признаков общие для обоих режимов: ожидаемо хуже без старта.
- Каждый режим учится на половине лотов, это может стоить точности в обоих режимах.

## Status

- **State:** done
- **Approved by user on:** 2026-10-16
- **Headline result:** одна модель с маскированием 50%: со стартом MdAPE 24.1%, промах > 50% 21.5%, pinball 0.148 (отдельная модель 23.2% / 21.1% / 0.145); без старта MdAPE 28.4%, промах > 50% 27.6%, pinball 0.182 (отдельная модель 27.4% / 26.8% / 0.176). Хуже в обоих режимах на всех четырёх фолдах.
- **Implication for next iteration:** остаются две модели за одним API: поле стартовой цены в форме необязательное, сервис выбирает модель по тому, заполнено ли оно. Для пользователя это выглядит как одна модель.
