# 32_first_sale_supply

## Question / hypothesis

Помогают ли модели 3 признаки предложения: сколько лотов той же модели (и в том же ценовом диапазоне) и всего легковых лотов опубликовано за 30 дней до первых торгов?

## Motivation

- **Sourcing strategy:** my-pick
- **Source(s):** B18: при большом предложении похожих машин покупатель выбирает, продажа сразу менее вероятна.
- **Why this matters:** это единственный новый источник информации о рынке в момент торгов, который есть в собранных данных.

## Method

- **Files touched:** `misc/scratch_2026-10-16/exp32.py`.
- **Change versus baseline (or previous experiment):** по каталогу всех статусов (только легковые, цена > 0): log(1 + число торгов) за 30 дней до публикации - всего, той же марки, той же марки+модели по названию, той же модели с ценой в пределах ±25%; варианты: все, только по модели, только общий.
- **Cross-validation:** честный CV из 26, кэш фолдов `m3.py`.
- **Out of scope for this experiment:** предложение на других площадках.

## Risks / things that could invalidate the result

- В API для свежего прогноза нужен свежий каталог (ежедневное обновление списков ЦДТ); если признаки не дадут заметного выигрыша, не принимаются.
