# 33_first_sale_labels

## Question / hypothesis

Меняет ли качество модели 3 очистка обучающей разметки: без статуса «Торги завершены» без договора и без первых торгов, для которых в каталоге нет полных 18 месяцев истории?

## Motivation

- **Sourcing strategy:** my-pick
- **Source(s):** B20; каталог начинается 2022-01-28, поэтому у торгов начала 2023 года предыдущие торги могли не попасть в каталог, и повторные торги ошибочно считаются первыми.
- **Why this matters:** шум в метке занижает качество и смещает калибровку.

## Method

- **Files touched:** `misc/scratch_2026-10-16/exp33.py`.
- **Change versus baseline (or previous experiment):** фильтры только на train (валидация без изменений): без «Complete»; первые торги с 2023-07-28; только 2024+.
- **Cross-validation:** честный CV из 26, кэш фолдов `m3.py`.
- **Out of scope for this experiment:** переопределение цепочек.

## Risks / things that could invalidate the result

- Меньше данных в train может перевесить выигрыш от чистоты.

## Status

- **State:** done
- **Approved by user on:** 2026-10-17 («максимально улучшай третью, пока не упрётся»)
- **Headline result:** текущая 0.3603; train с 2023-07-28 (полные 18 мес. истории) 0.3605; без «Complete» 0.3624; только 2024+ 0.3682 (ECE 0.032, средний прогноз 16.8% при факте 14.4%).
- **Implication for next iteration:** не принимается: очистка разметки не помогает, а потеря данных начала 2023 года вредит. Шум в определении первых торгов на качество заметно не влияет.
