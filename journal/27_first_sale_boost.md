# 27_first_sale_boost

## Question / hypothesis

Улучшат ли модель 3 бустинг CatBoost от логистической регрессии (B16) и отношение начальной цены к типичной (B17)?

## Motivation

- **Sourcing strategy:** my-pick (B16, B17)
- **Source(s):** 26: средний прогноз CatBoost по фолдам 13-24% при факте 11-17% (деревья не экстраполируют падающий тренд); 25: проданные сразу лоты имели старт примерно на 20% ниже типичного.
- **Why this matters:** калибровка по времени - главное для доверия к цифре «продаётся сразу в X%».

## Method

- **Files touched:** `misc/scratch_2026-10-16/exp27.py`; `src/models/first_sale.py` - только при выигрыше.
- **Change versus baseline (or previous experiment):** B16 - CatBoost обучается с `baseline` = логит OOF-прогноза логистической регрессии (GroupKFold по должнику), итог = сигмоида (логит логистической + сырой ответ CatBoost). B17 - признак log(старт) − P50 модели 2 (линейная на log первого старта, OOF по должнику внутри train, обучение на связанных проданных лотах, опубликованных до начала квартала), монотонно убывающий. Варианты: текущий, B16, B17, B16+B17.
- **Cross-validation:** честный CV из 26.
- **Out of scope for this experiment:** B18-B20.

## Risks / things that could invalidate the result

- Модель 2 учится только на проданных лотах (отбор), для первых торгов без продажи её оценка может быть смещена.

## Status

- **State:** done
- **Approved by user on:** 2026-10-17 (основной вектор работ, «думать, как третью модель улучшать»)
- **Headline result:** текущий log loss 0.3603 / Brier 0.1085 / AUC 0.7625; B17 0.3586 / 0.1082 / 0.7642 (AUC лучше на всех 4 фолдах на 0.0015-0.002, log loss - на 3 из 4); B16 0.4499 / 0.1254 / 0.7466 - хуже; B16+B17 0.4619.
- **Implication for next iteration:** оба не принимаются. B16: бустинг от OOF-логита логистической ломает калибровку (в train базовая линия по OOF, на валидации - от модели на всём train, деревья учат разницу между ними). B17 стабилен, но выигрыш около 0.002 по AUC не стоит зависимости модели 3 от модели 2: отношение к рынку уже несёт тот же сигнал.
