# 30_first_sale_market

## Question / hypothesis

Станет ли модель 3 точнее, если рыночную оценку для отношения цены брать из полного ансамбля задачи 1 (P50 линейной и CatBoost), а не только из линейной модели, и добавить ширину рыночного коридора?

## Motivation

- **Sourcing strategy:** my-pick
- **Source(s):** главный признак модели 3 - отношение начальной цены к рынку; у ансамбля задачи 1 MdAPE 26.5% против 26.8% у линейной.
- **Why this matters:** точнее рынок - точнее главный признак.

## Method

- **Files touched:** `misc/scratch_2026-10-16/exp30.py`.
- **Change versus baseline (or previous experiment):** рынок = P25/P50/P75 `ensemble.predict` без старта (OOF по должнику в train); варианты: только P50, P50 + ширина log P75 − log P25, P50 + нормированное отношение (log старт − log P50) / ширина с монотонностью.
- **Cross-validation:** честный CV из 26, кэш фолдов `m3.py`.
- **Out of scope for this experiment:** другие признаки.

## Risks / things that could invalidate the result

- Оценка ансамбля дороже: в API рынок для шкалы считается один раз на запрос, это допустимо.
