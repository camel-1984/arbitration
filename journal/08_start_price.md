# 08_start_price

## Question / hypothesis

Насколько уменьшится ошибка, если дать модели оценку управляющего - начальную цену первых торгов этого лота - как признак?

## Motivation

- **Sourcing strategy:** B7
- **Source(s):** разбор ошибок после 06: 44% дисперсии лог-ошибки объясняется отношением стартовой цены управляющего к прогнозу; в 300 худших завышениях старт в среднем 0.57 от нашего P50. Запланированный эксперимент из PROJECT_CONTEXT (оценка управляющего по Авито как признак, не как таргет). Пользователь согласился попробовать 2026-10-16.
- **Why this matters:** управляющий видел машину и рынок; текст лота этого почти не передаёт. Таргет остаётся фактической ценой продажи, поэтому модель не повторяет ошибки управляющих, а учит систематическую скидку торгов к его оценке.

## Method

- **Files touched:** `src/collect/cdtrf.py` (режим `--list-all`: только страницы каталога всех статусов, без карточек), `src/parse/cdtrf_list.py` (новый: список → `data/interim/cdtrf_trades.parquet` без персональных данных: хеш ФИО должника, хеш VIN из названия, марка и модель), `src/parse/cdtrf.py` (тот же хеш ФИО в карточках), `src/dataset/build.py` (связка этапов), `src/models/*` (признак).
- **Change versus baseline (or previous experiment):** для каждого проданного лота ищутся более ранние торги того же должника по тому же ТС (хеш VIN, иначе марка + модель) в пределах 18 месяцев; начальная цена первых торгов `first_price` = цена самого раннего аукциона цепочки. Если связка не нашлась, для публичного предложения `first_price` = начальная цена / 0.9 (по 127-ФЗ публичное предложение начинается с цены повторных торгов), для аукциона - его начальная цена. Признак `log(first_price)`. Сравниваются ансамбль 07 и тот же ансамбль с признаком.
- **Cross-validation:** честный CV из 04, данные 06.
- **Out of scope for this experiment:** замена основной модели; основная модель без стартовой цены остаётся независимым ориентиром.

## Risks / things that could invalidate the result

- Циркулярность механики: на первых торгах цена продажи не ниже старта, на публичном предложении следует графику от него. Часть прироста - это механика, а не знание о машине; так же будет и в продакшене, где старт ставится после прогноза.
- Смена продукта: прогноз становится «ожидаемая цена при вашей оценке» и зависит от качества оценки управляющего; при инференсе нужно вводить планируемую цену первых торгов.
- Ошибки связки (разные машины одного должника одной модели, неточность правила 0.9) шумят в признаке; доля связанных лотов и согласие с правилом 0.9 проверяются.
- ФИО должника используется только как хеш для связки и не хранится.

## Status

- **State:** done
- **Approved by user on:** 2026-10-16
- **Headline result:** каталог: 72 000 легковых торгов всех статусов с 2022 года (43 751 «не состоялись»), 144 страницы. Связка: 8843 лота по названию или VIN, 1175 по марке и модели, 3308 публичных предложений по правилу 0.9 (обезличенные названия «Продажа имущества должника ...»). У связанных публичных предложений старт этапа / старт первых торгов = 0.90 от 25-го до 90-го перцентиля, то есть правило 0.9 подтверждено. CV (ансамбль с калибровкой 12): без старта MdAPE 27.4%, промах > 50% 26.8%, покрытие 50.8%, pinball 0.176; со стартом MdAPE 23.2%, промах > 50% 21.1%, покрытие 54.6%, pinball 0.145. Эвристика «старт × типичная скидка» без модели: MdAPE 29.0%, промах > 50% 33.8% - хуже обеих моделей. По этапу: со стартом публичное предложение 21.3%, аукцион 25.5% (у эвристики аукцион 18.2%: на первых торгах цена почти равна старту). Описательно: при старте ≤ 0.8 прогноза без старта 72% лотов уходят на первых торгах, цена ≈ 0.61 прогноза; при старте в 2-3 раза выше прогноза - 13%, цена ≈ 1.27 прогноза (только проданные лоты).
- **Implication for next iteration:** оценка управляющего - самый сильный признак проекта (-4.2 п.п. MdAPE, -18% pinball), и модель лучше и оценки, и себя без неё: она учит скидку торгов к оценке и поправку на машину. Слабое место - лоты, проданные на первых торгах: распределение цены двугорбое (≈ старт или ≈ 0.6 старта), квантильный коридор это плохо описывает; возможный продукт - два сценария (первые торги / публичное предложение). Основная модель без старта остаётся независимым ориентиром; в UI нужно поле «планируемая начальная цена первых торгов».
