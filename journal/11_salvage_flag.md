# 11_salvage_flag

## Question / hypothesis

Уменьшатся ли сильные завышения, если `major_defect` будет ловить годные остатки и разукомплектованные машины, а прицепы будут удалены из данных?

## Motivation

- **Sourcing strategy:** my-pick
- **Source(s):** чтение текстов 25 лотов с завышением прогноза больше чем в 2.5 раза и без флагов дефектов: «годные остатки от ТС», «разукомплектован, отсутствует двигатель», «прицеп к легковому автомобилю». По корпусу: годные остатки и «на запчасти» - 34 лота валидации с медианной лог-ошибкой -0.75 (MdAPE 111%), прицепы к легковым - 34 лота во всех данных.
- **Why this matters:** это лоты, где прогноз ошибается в разы; управляющий видит такое по тексту сразу, и модель должна тоже.

## Method

- **Files touched:** `src/features/text.py` (паттерны `major_defect`: годные остатки, на запчасти, разукомплектован, для разбора, без или отсутствует двигатель), `docs/labeling_guide.md` (определение флага дополнено теми же случаями), `src/dataset/build.py` (правило очистки «прицеп»: «прицеп к легковому» и марка не найдена).
- **Change versus baseline (or previous experiment):** только эти правила.
- **Cross-validation:** честный CV из 04; ансамбль 07.
- **Out of scope for this experiment:** флаг такси (36 лотов, смещение -0.3), цвет (без эффекта).

## Risks / things that could invalidate the result

- Определение флага в гайде изменено; старая разметка эталона могла ставить 0 таким лотам. На dev2 и flags метрики флага не изменились (P/R 0.94/1.0 и 1.0/0.93, ошибки старые).

## Status

- **State:** done
- **Approved by user on:** 2026-10-16 (общее разрешение работать над улучшением модели)
- **Headline result:** доля `major_defect` 6.2%; лотов 13362 → 13328 (34 прицепа). Ансамбль: MdAPE 27.4% (без изменений), промах > 50% 26.8%, покрытие 44.5%, pinball 0.179 → 0.176.
- **Implication for next iteration:** выигрыш в хвостах, а не в медиане. Большинство сильных завышений - короткие тексты без описания состояния: этого текст не исправит, нужна оценка управляющего (08).
