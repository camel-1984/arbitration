# 06_card_features

## Question / hypothesis

Дают ли прирост признаки из карточки, которые мы ещё не используем и которые известны до торгов: регион по коду арбитражного суда, число фото лота, управляющий и его СРО?

## Motivation

- **Sourcing strategy:** my-pick
- **Source(s):** 05 и эксперименты с CatBoost (CTR, калибровка, гибрид с линейной моделью) упёрлись в один уровень около 28%: модель ограничена информацией, а не алгоритмом. `lot_regionID` пропущен у 55% лотов, а номер дела (`dealNum`, «А79-...») есть у 97%, и код суда совпадает с регионом в 100% случаев на выборке 1488 карточек. Фото есть у 9% лотов.
- **Why this matters:** цены на подержанные машины различаются по регионам (Москва, Дальний Восток с праворульными японцами); управляющий отвечает за описание, осмотр и стартовую цену.

## Method

- **Files touched:** `src/parse/cdtrf.py` (код суда, число фото, хеш ИНН управляющего, id СРО), `src/models/linear.py`, `src/models/catboost_model.py`.
- **Change versus baseline (or previous experiment):** регион = `lot_regionID`, при пропуске - регион по коду суда (соответствие суд → регион выучивается на лотах, где есть оба); `n_images` числом; `arbman_key` и `arbman_sro` категориальными. Сравниваются три набора: (a) регион + фото, (b) + СРО, (c) + управляющий. В CatBoost включено исправление CTR (`Borders:TargetBorderCount=15`) из предварительных прогонов, иначе категориальные признаки кодируются по бинарному таргету.
- **Cross-validation:** честный CV из 04 на данных 05.
- **Out of scope for this experiment:** стартовая цена, LLM.

## Risks / things that could invalidate the result

- Управляющий как признак частично возвращает в модель его ценовую политику (высокая стартовая цена → выше цена продажи на аукционе), то есть то смещение, от которого мы отказались, убрав стартовую цену. Если (c) даст заметный прирост, это решение для пользователя, а не автоматический выбор.
- Для нового управляющего эффект неизвестен (категория «редкий»), поэтому прирост на CV может быть выше, чем у нового пользователя.
- Хеш ИНН управляющего - псевдоним публичного лица (управляющие публикуются в ЕФРСБ), сам ИНН не хранится.
