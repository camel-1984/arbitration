# 07_ensemble

## Question / hypothesis

Даёт ли среднее квантилей линейной модели и CatBoost (в лог-шкале, веса 50/50) меньшую ошибку, чем каждая модель отдельно?

## Motivation

- **Sourcing strategy:** B5
- **Source(s):** пункт бэклога B5; в 06 модели вышли на одинаковый pinball (0.184 и 0.185) при разной структуре: линейная лучше по хвосту ошибок, CatBoost ловит взаимодействия.
- **Why this matters:** ансамбль моделей с некоррелированными ошибками уменьшает дисперсию прогноза без новых данных.

## Method

- **Files touched:** `src/models/ensemble.py` (новый), `src/models/catboost_model.py` (CTR `Borders:TargetBorderCount=15`, depth 4, l2 10, 1500 итераций; признаки из 06).
- **Change versus baseline (or previous experiment):** P25/P50/P75 = exp(0.5 · log q_linear + 0.5 · log q_catboost), затем сортировка. Вес не подбирается по CV, а задан заранее; перебор весов 0-1 на сохранённых прогнозах 06 показал плоский оптимум 0.3-0.7.
- **Cross-validation:** честный CV из 04, данные 06.
- **Out of scope for this experiment:** стекинг с обучаемыми весами, калибровка коридора.

## Risks / things that could invalidate the result

- Признаки и параметры CatBoost выбирались на тех же фолдах (CTR, глубина, набор признаков 06), так что цифры CV немного оптимистичны; честная оценка - один прогон на тесте 2026.
- Покрытие ансамбля ниже, чем у линейной модели: среднее двух квантилей сужает коридор.
