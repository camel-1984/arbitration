# 09_model_aliases

## Question / hypothesis

Есть ли прирост от ручного словаря для оставшихся редких строк марка + модель (кириллица, заводские коды, мусор), которые автоматическая нормализация 05 не свела?

## Motivation

- **Sourcing strategy:** user
- **Source(s):** вопрос пользователя 2026-10-16, сколько лотов ещё разобрано как разные модели; выборка 100 редких комбинаций после 05: около трети - та же машина под другим именем.
- **Why this matters:** проверяет, остался ли выигрыш в разборе текста, прежде чем тратить время на LLM-нормализацию.

## Method

- **Files touched:** `labels/model_aliases.csv` (новый, 150 строк, разметка Claude по списку 519 редких строк без текстов лотов), `src/features/normalize.py` (словарь применяется первым), `src/dataset/build.py` (коммерческий фильтр: ГАЗель и её коды A21R32 и т.п., УАЗ 452, Профи).
- **Change versus baseline (or previous experiment):** только явные дубли, коды и мусор; настоящие редкие модели не трогаются.
- **Cross-validation:** честный CV из 04.
- **Out of scope for this experiment:** LLM.

## Risks / things that could invalidate the result

- Словарь размечен по коротким строкам без контекста; часть кодов (Kia GE, Chevrolet Клау) оставлена как есть из-за неоднозначности.
- Коммерческий фильтр убрал 36 лотов, состав данных немного изменился.

## Status

- **State:** done
- **Approved by user on:** 2026-10-16 (общее разрешение работать над улучшением модели)
- **Headline result:** синглтонов 390 → 267, лотов в комбинациях < 5 лотов 1020 → 786, лотов 13398 → 13362. CV: линейная 28.1% / pinball 0.184, CatBoost 29.1% / 0.187, ансамбль MdAPE 27.4%, промах > 50% 26.8%, покрытие 44.1%, pinball 0.179 (07: 27.3% / 0.180) - в пределах шума.
- **Implication for next iteration:** разбор текста больше не узкое место; LLM-нормализация не нужна. Разница CatBoost между версиями данных (28.4% и 29.1%) показывает его шум около 0.5 п.п.
