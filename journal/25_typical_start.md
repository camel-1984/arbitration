# 25_typical_start

## Question / hypothesis

Насколько точно по характеристикам машины предсказывается начальная цена первых торгов, которую ставят управляющие, и можно ли выдавать её квартили как «типичную начальную цену» (модель 2, design doc 2.1)?

## Motivation

- **Sourcing strategy:** user (B14, основной вектор работ 2026-10-17)
- **Source(s):** ответ пилотного пользователя: лучший исход - продажа на первых торгах, значит, главный вопрос - какую начальную цену ставить. По закону начальная цена - рыночная стоимость, и практика других управляющих служит её защищаемой оценкой.
- **Why this matters:** закрывает вопрос «какую цену ставить» без причинной задачи об оптимальной цене; модель 3 (B10) будет строить шкалу цен вокруг этого значения.

## Method

- **Files touched:** scratch-скрипт `misc/scratch_2026-10-16/exp25.py`; новый модуль в `src/models/` - только после результата.
- **Change versus baseline (or previous experiment):** те же признаки и модели, что в задаче 1 без старта (бейзлайн-каскад, линейная, CatBoost, ансамбль 50/50), с теми же гиперпараметрами без подбора; таргет - log(first_price) вместо log(цены продажи). Лоты: стартовая цена найдена связкой этапов («название или VIN», «марка и модель»), правило 0.9 исключено (это пересчёт цены публичного предложения, а не цена, поставленная управляющим). Коридор калибруется последовательной схемой из 12 (`calib_k2.py`), k по кварталам 2024Q3-2025Q4.
- **Cross-validation:** честный CV из 04 (фолды и фильтр по `sold_at` те же, что у задачи 1; фильтр по продаже здесь избыточен, но строже).
- **Out of scope for this experiment:** непроданные лоты из каталога всех статусов (в каталоге нет признаков из текста); подбор гиперпараметров.

## Risks / things that could invalidate the result

- Отбор по продаже: в данных только лоты, которые в итоге продались, а лоты с завышенным стартом, так и не проданные, выпадают. Модель занижает «типичный» старт относительно всех первых торгов.
- Связка «марка и модель» может цеплять не те торги одного должника.
- Те же фолды, что у задачи 1 (оптимизм CV), но гиперпараметры не подбираются.
