# API для веб-интерфейса

Сервис `src/api/app.py` (FastAPI) раздаёт сайт из `web/` и методы ниже. Запуск из корня репозитория: `PYTHONPATH=. .venv/bin/python -m uvicorn src.api.app:app --port 8001`. `/api/extract` и журнал пилота работают; `/api/predict` пока отвечает 501, и `web/app.js` строит ответ в демо-режиме по этому же контракту.

## POST /api/extract

Запрос: `{"text": "описание лота"}`. Если в тексте есть ссылка на карточку ЦДТ (`torgi.cdtrf.ru/.../trades/<id>`), сервис сам скачивает карточку (один запрос), разбирает её парсером `src/parse/cdtrf.py` (с маскировкой персональных данных) и дополнительно возвращает `region`, `first_price` (начальная цена, только для аукциона), `description` (замаскированный текст) и `source` (`trade_id`, `trade_type`, `url`, `passenger` - лот только из категории «Легковой транспорт»). Ошибка загрузки - 502.

Ответ: поля формы, извлечённые из текста (`src/features/text.py` и нормализация моделей). Неизвестное поле - `null`, флаги - 0 или 1.

```json
{"make": "Kia", "model": "Rio", "year": 2015, "power_hp": 123, "engine_cc": 1591,
 "major_defect": 0, "damaged": 1, "no_keys_or_docs": 0, "pledge": 0, "arrest_or_ban": 0, "location_unknown": 0}
```

## POST /api/predict

Запрос: поля формы. `make`, `model`, `year` обязательны, остальные можно не указывать (`null`). `first_price` - начальная цена, которую указал управляющий.

```json
{"make": "Kia", "model": "Rio", "year": 2015, "region": "77", "power_hp": 123, "engine_cc": 1591,
 "first_price": 850000, "major_defect": 0, "damaged": 1, "no_keys_or_docs": 0, "pledge": 0, "arrest_or_ban": 0, "location_unknown": 0}
```

Ответ:

```json
{
  "typical_start": {"p25": 820000, "p50": 900000, "p75": 980000},
  "market": {"p25": 610000, "p50": 700000, "p75": 790000},
  "curve": [
    {"price": 630000, "p_first": 0.54, "sale": {"p25": 470000, "p50": 560000, "p75": 650000}},
    {"price": 850000, "p_first": 0.27, "sale": {"p25": 540000, "p50": 640000, "p75": 750000}, "own": true},
    {"price": 900000, "p_first": 0.22, "sale": {"p25": 550000, "p50": 660000, "p75": 770000}, "typical": true}
  ],
  "low_reliability": false,
  "factors": [{"label": "Возраст автомобиля: 11 лет", "effect": -0.18}],
  "comparables": [{"make": "Kia", "model": "Rio", "year": 2014, "sale_date": "2025-12-02", "sale_price": 640000, "url": null}]
}
```

- `typical_start` - модель 2 (`src/models/typical_start.py`): квартили начальной цены первых торгов, которую ставят другие управляющие.
- `market` - модель 1 без начальной цены (`src/models/ensemble.py`): квартили цены продажи похожих автомобилей.
- `curve` - шкала начальных цен по возрастанию. Точки: P50 типичной цены × 0.7, 0.8, ..., 1.3 (округление до 10 тыс., для дешёвых машин до 5 или 1 тыс.) и цена управляющего, если указана (`own: true`); точка типичной цены помечена `typical: true`. `p_first` - модель 3: доля похожих лотов, проданных на первых торгах при такой цене, монотонно убывает с ростом цены. `sale` - модель 1 с начальной ценой: квартили итоговой цены продажи при этой начальной цене с учётом обоих исходов (продажа сразу или после снижения).
- `low_reliability` - мало похожих лотов в истории (редкая марка или модель), интерфейс показывает предупреждение.
- `factors` - главные факторы модели 1 в процентах (`src/models/explain.py`), `comparables` - похожие проданные лоты (`src/models/comparables.py`), проданные до даты запроса.

Если управляющий вводит на экране результата цену, которой нет в `curve`, интерфейс повторяет запрос с этим `first_price`.

## Сроки продажи

Не входят в ответ `/api/predict`: лежат в `web/catalog.json` (`timing_days`, считает `src.dataset.web_catalog` по лотам 2025 года). `first_auction` - дни от публикации до продажи для лотов, проданных на первых торгах; `later` - от публикации первых торгов до продажи для остальных. Квартили p25, p50, p75.

## Журнал пилота

Хранится в `data/pilot/journal.json` (не в git), без базы данных.

- `GET /api/pilot` - все записи.
- `POST /api/pilot` - новая запись: `{"lot": {...}, "blind_estimate": 420000, "chosen_price": 540000, "forecast": {"demo": false, "typical_start": {...}, "market": {...}, "chosen": {точка curve}}}`. `blind_estimate` - оценка цены продажи управляющим, введённая до расчёта. Ответ - запись с `id`, `created_at` и пустым `outcome`.
- `PATCH /api/pilot/{id}` - исход: `{"sold_first": true | false | null, "sale_price": 380000, "sale_date": null, "note": null}`.

Страница `web/pilot.html` показывает записи, принимает исход и считает типичную ошибку оценки управляющего и прогноза (медиана абсолютной ошибки в процентах), а также ожидаемую и фактическую долю продаж на первых торгах.
