# ML System Design: прогноз цены продажи легкового автомобиля на торгах по банкротству

## 1. Цели и предпосылки

### 1.1. Проблема

Имущество банкрота продаётся на электронных торгах: первые торги, повторные торги, публичное предложение. Стартовую цену ставит арбитражный управляющий, обычно вручную по объявлениям на Авито. Завышенная цена затягивает продажу на месяцы, заниженная уменьшает выручку кредиторов и создаёт риск оспаривания.

### 1.2. Цель

Показать управляющему, за сколько легковой автомобиль, вероятно, будет продан на торгах по банкротству: диапазон цен, за которые похожие ТС продавались на завершённых торгах, и сами эти лоты как обоснование. Ответ даётся в процентах по квартилям, например: «25% похожих ТС продаются дешевле 610 тыс. руб., 50% дешевле 700 тыс., 75% дешевле 790 тыс.» Стартовую цену выбирает управляющий, прогноз служит ему ориентиром.

### 1.3. Пользователь и критерии успеха

Пользователь - арбитражный управляющий (АУ), пилотный пользователь - практикующий АУ.

- Модель: на торгах последнего периода, которые модель не видела при обучении, её типичная ошибка в цене меньше, чем у бейзлайна, а в коридор P25-P75 попадает около 50% фактических цен. Покрытие показывает только калибровку: коридор должен быть ещё и уже, чем у бейзлайна.
- Пилот (бизнес-метрика): управляющий сначала сам, без прогноза, оценивает ожидаемую цену продажи лота (чтобы не было эффекта якоря), потом смотрит прогноз. После продажи лотов сравнивается, чья оценка ближе к фактической цене продажи. Успех - ошибка прогноза не больше ошибки оценки управляющего. Ограничение: управляющий выбирает стартовую цену уже с оглядкой на прогноз, а на публичном предложении цена продажи следует графику от стартовой, поэтому прогноз частично влияет на исход и сравнение смещено в пользу модели. По каждому лоту записываются слепая оценка, прогноз и выбранная стартовая цена, отдельно смотрятся лоты, проданные на первых торгах с конкуренцией. Проверка занимает не меньше месяца, и на единицах лотов одного управляющего это первые наблюдения, а не статистическое доказательство.

### 1.4. Границы проекта

Входит: легковые автомобили (категория площадки «Легковой транспорт»), вся Россия, только завершённые торги. Не входит: грузовой и коммерческий транспорт, прицепы и спецтехника (следующая версия), покупатели и кредиторы как аудитория, недвижимость, внешние рыночные цены, рекомендация стартовой цены. Последнее - причинный вопрос (что будет при цене S): для него нужны данные о несостоявшихся торгах, причины срыва которых надёжно не разделяются (цена, процедура, отказ победителя), а влияние цены смешано со скрытым состоянием ТС. Инструмент не заменяет решение управляющего.

### 1.5. Ограничения

- Цена продажи есть только у проданных лотов, поэтому прогноз может быть завышен (selection bias).
- Решения управляющих частично влияют на таргет: на первых торгах цена продажи не ниже стартовой, на публичном предложении она следует графику.
- Скрытое состояние ТС модели не видно. Прогноз - ориентир для типичного ТС, управляющий может вручную отметить факторы состояния, при нетипичном лоте модель предупреждает о низкой надёжности, отклонения от коридора логируются с причиной.
- Сильный дрейф цен после 2022 года.

## 2. Методология

### 2.1. Постановка ML-задачи

- Объект: проданный лот с одним легковым автомобилем (лоты с несколькими ТС исключаются).
- Таргет: log(цена продажи). Стартовая цена управляющего как таргет отвергнута: модель повторяла бы их ошибки.
- Признаки: характеристики ТС, флаги состояния из текста, регион, дата. Стартовая цена и сведения о результатах торгов не используются.
- Задача: квантильная регрессия P25/P50/P75, функция потерь pinball loss.
- Метрики: MdAPE по P50, покрытие коридора P25-P75; вспомогательная - доля лотов с ошибкой P50 больше 50% (сильные промахи, которые медиана не видит); отдельно по этапу продажи и сегментам (возраст, ценовой диапазон).
- Бейзлайн: медиана цен похожих лотов, проданных ранее. Лестница моделей: бейзлайн → линейная регрессия → CatBoost.

### 2.2. Данные

Сокращения:

- ЕФРСБ - Единый федеральный реестр сведений о банкротстве (bankrot.fedresurs.ru), официальный реестр объявлений о торгах и их результатах.
- ЭТП - электронная торговая площадка, сайт, на котором проходят сами торги.
- ЦДТ - Центр дистанционных торгов (torgi.cdtrf.ru), одна из крупнейших ЭТП по банкротству. Другие крупные: МЭТС (Межрегиональная электронная торговая система), РАД (Российский аукционный дом), НИС (Новые информационные сервисы).
- 127-ФЗ - федеральный закон «О несостоятельности (банкротстве)».
- ИНН - идентификационный номер налогоплательщика.
- VIN - идентификационный номер транспортного средства.

ЕФРСБ закрыт защитой от автоматического доступа, поэтому данные берутся с ЦДТ, где проходят сами торги. Сведения о торгах публичны по 127-ФЗ.

- Объём: проданные лоты категории «Легковой транспорт», опубликованные с 01.01.2024, около 15 тыс. (весь архив с 2020 года - около 26 тыс.).
- По каждому лоту: описание, начальная и итоговая цена, ход торгов.
- Характеристики ТС извлекаются из текста описания. При парсинге в тексте маскируются VIN, госномера, телефоны, ФИО, ИНН и СНИЛС. Из VIN сохраняются только код производителя (WMI, первые 3 символа), код года выпуска (10-й символ) и хеш для поиска повторных продаж. ИНН должника заменяется хешем.
- Ограничения: одна площадка из нескольких, характеристики ТС нужно извлекать из свободного текста, регион указан не во всех карточках. Должники в легковых лотах почти всегда физические лица.

### 2.3. Схема валидации

- Данные: проданные лоты, опубликованные с 01.01.2024. Лоты, опубликованные менее чем за 3 месяца до даты сбора, исключаются: из них в данных остались только быстро проданные.
- Дата публикации - дата начала приёма заявок (известна до торгов). Разбиение по этой дате, без перемешивания.
- Выбор модели и подбор гиперпараметров: кросс-валидация со скользящим окном на 2024-2025 годах, 4 фолда. Обучение на всех данных до начала квартала, проверка на квартале 2025 года.
- Итоговая оценка: модель обучается на 2024-2025 годах и один раз проверяется на 2026 годе.
- Дубли одного ТС (повторная продажа) выявляются по хешу VIN и удаляются.
- Предобработка обучается только на обучающей части фолда. Бейзлайн использует только лоты, проданные раньше оцениваемого.
- Достаточность объёма данных проверяется кривой обучения.

### 2.4. Извлечение признаков из текста

- Марка, модель, год, мощность (л.с.), объём двигателя (куб. см) и флаги состояния (`major_defect`, `damaged`, `no_keys_or_docs`, `pledge`, `arrest_or_ban`, `location_unknown`) извлекаются регулярными выражениями из названия и описания лота (`src/features/text.py`). Мощность и объём берутся только из описания.
- Качество проверяется на эталоне `labels/gold.csv`: 127 лотов, из них dev - 52 лота, размеченных человеком, test - 75 лотов, размеченных Claude. Правила разметки - `docs/labeling_guide.md`, лоты с `exclude` = 1 в оценку не входят.
- Метрики (`python -m src.labels.evaluate_extraction --split dev|test|all`): для значений - доля верно извлечённых, число неверных, пропущенных и лишних (допуск 0,5 л.с. для мощности и 1 куб. см для объёма), для флагов - precision и recall.
