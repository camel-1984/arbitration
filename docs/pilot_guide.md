# Как поставить и запустить (Windows)

Программа работает у вас на компьютере: сайт открывается в браузере, интернет нужен только для установки и для загрузки лотов по ссылке с ЦДТ.

## Один раз: доступ

Репозиторий закрытый. Зарегистрируйтесь на https://github.com (бесплатно) и пришлите свой логин. Вам придёт приглашение на почту: откройте его и нажмите «Accept invitation».

## Один раз: установка

1. Установите Python 3.12: https://www.python.org/downloads/release/python-3129/ → внизу страницы «Windows installer (64-bit)». В первом окне установщика поставьте галочку **«Add python.exe to PATH»**, затем «Install Now».
2. Установите Git: https://git-scm.com/download/win → скачается установщик, все шаги можно оставить по умолчанию.
3. Откройте терминал: `Win + R`, введите `cmd`, Enter.
4. Скачайте программу (папка `arbitration` появится в вашей папке пользователя):

   ```
   git clone https://github.com/camel-1984/arbitration.git
   ```

   При первом скачивании откроется окно входа в GitHub: войдите под своим логином. Больше вводить пароль не придётся.

## Каждый раз: запуск

1. Откройте папку `arbitration` (обычно `C:\Users\<ваше имя>\arbitration`) и дважды щёлкните `start.bat`.
2. При первом запуске программа несколько минут устанавливается. Потом браузер сам откроет `http://localhost:8001`.
3. Чёрное окно не закрывайте, пока работаете: это и есть программа. Закрыли окно - программа выключилась.

## Как пользоваться

1. Вверху выберите режим. «До выставления» - лот ещё не выставлен и вы выбираете начальную цену: вставьте описание автомобиля (например, из описи или черновика объявления) и нажмите «Заполнить поля по описанию» или заполните поля вручную. «Уже на торгах» - лот уже на ЦДТ: вставьте ссылку на карточку и нажмите «Загрузить», программа сама заполнит поля и посчитает.
2. Проверьте поля: марку, модель, год, состояние. Если что-то распознано неверно, поправьте.
3. **До расчёта** впишите в поле «Ваша оценка цены продажи», за сколько, по-вашему, машина продастся. Это главное для пилота: оценка должна быть сделана до того, как вы увидите прогноз.
4. Нажмите «Оценить». Вверху - сколько обычно ставят и как часто похожие лоты продаются сразу при разной цене, ниже - что будет при выбранной цене.
5. Нажмите «Сохранить в журнал».

## Когда выставите лот

Откройте «Журнал пилота», раскройте у лота «Ссылка на лот, исход и комментарий», вставьте ссылку на карточку ЦДТ и нажмите «Сохранить исход». Это нужно не для расчёта, а для проверки прогноза: по ссылке исход торгов потом заберётся с площадки автоматически, и вписывать его руками не придётся.

## После торгов

1. Откройте «Журнал пилота» (ссылка «Журнал пилота» под результатом расчёта или адрес `http://localhost:8001/pilot.html`).
2. По желанию раскройте у лота «Исход и комментарий» и впишите, что знаете: продан ли сразу, за сколько, комментарий. Всё необязательно: если лот сохранён по ссылке на ЦДТ, исход можно забрать с площадки автоматически. Нажмите «Сохранить исход».
3. Раз в неделю или когда удобно нажмите «Скачать журнал» и пришлите файл `pilot-journal-....json`.

## Обновление

Когда вам скажут, что вышла новая версия, дважды щёлкните `update.bat`, затем снова `start.bat`. Журнал при обновлении сохраняется (он лежит в `data\pilot\journal.json`).

## Если что-то не работает

- «Python не найден» - установите Python 3.12 с галочкой «Add python.exe to PATH» и запустите `start.bat` снова.
- Браузер открылся раньше, чем программа запустилась, и показал ошибку - подождите несколько секунд и обновите страницу.
- Любая другая ошибка - сделайте скриншот чёрного окна и пришлите.
